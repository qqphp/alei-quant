## 启动

已准备好本机环境时，在项目目录运行：

```powershell
.\scripts\start.ps1
```

浏览器打开 <http://127.0.0.1:8000>。停止：`.\scripts\stop.ps1`。前端修改后运行 `start.ps1 -Build`，须先停止已登记服务。

启动入口会等待 API、配置中的数据库和工作进程就绪（最长 20 秒），检查通过后才提示成功。失败时停止本次登记的服务，诊断日志保留在 `runtime`。

首次手动安装：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
$env:PYTHONPATH = "$PWD\backend"
$env:PYTHONUTF8 = '1'
.\.venv\Scripts\python.exe -m stockapp.bootstrap
cd frontend
npm ci
npm run build
cd ..
.\scripts\start.ps1
```

初始化交互读取 PostgreSQL 管理员密码，只创建尚不存在的 `stock_alei` 和独立应用账号。`.env` 含本机应用连接秘密，不公开、不提交。已有数据库不删除数据；已有应用角色而配置缺失时不会自动重置密码。

备份运行 `.\scripts\backup.ps1`，完成目录位于 `runtime/backups`，含一致性数据库快照、策略和引擎归档、当前程序与依赖锁。备份不包含管理员密码。

恢复验收：设置 `PYTHONPATH` 后运行 `.\.venv\Scripts\python.exe -m stockapp.maintenance restore-check --directory <备份目录>`。程序交互读取管理员密码，创建名称以 `stock_alei_restore_` 开头的独立库，不覆盖主库；在该副本验证旧数据读取和原引擎/模型重算，保存 `restore-verification.json`。验证库曾保留并含明确标记的模拟修订，不作为真实行情库；截至2026-10-11，这18个本地验收库已清理，复验时可从对应备份重建。最终备份为 `runtime/backups/20261011-143926-574371`，独立恢复、全部源值及典型报告重算已实际通过，见[最终恢复步骤](docs/final-restore-procedure.md)。恢复后生成的完成说明与核验证据位于该备份的 `post-verification` 附件目录，和原快照文件摘要分开保存。

## 使用

1. **数据中心**：指定证券、区间和周期采集。浏览页面只读取已发布的 PostgreSQL 数据。接口采集可读取财务、业绩、行业、指数成分和宏观，参数和字段参照每项官方说明。
2. **市场行情**：默认列出已有日线的股票，可切换全部证券、自选、类型、交易所、当前上市状态和稳定排序；提供股票/ETF 分开的共同完整日统计与异动榜单。详情包含 K 线、MA、估值、基本资料、财务、分红记录。其它周期需先入库。
3. **回测研究**：先保证所选股票及基准的完整交易日行情、足够的预热数据和公司行动覆盖，再提交。默认示例股票池为浦发银行、平安银行、贵州茅台；属于人工选定样例，不表示历史全市场无选择偏差。
4. **策略模型**：从本地受信任目录安装。示例包在 `strategies/ma_cross`，清单、参数和入口均可阅读。版本复制到 `runtime/strategies`，报告引用不会随原文件修改而改变。

数据中心新增历史证券池查询、区间覆盖检查、快照回填和当日 CSV。多年行情可以按历史成员并集回填，避免只用结束日名单；来源名称、成员和交易状态不保证历史首次发布真值，实际新代码可在启用前被回溯返回。顺序与限制见 [历史证券池说明](docs/historical-universe.md)。

经典示例的来源、首日初始化、等权资金、失败订单和预热约定见 [双均线说明](docs/classic-ma-strategy.md)。

模型可以显式声明 `universe`，按信号前已就绪的固定版本完整快照接收代码/源状态；七频率、来源引用及回溯限制见 [模型历史池输入](docs/historical-universe-input.md)。已核验特殊源记录处理见 [300114代码变更](docs/research/300114-code-change.md)、[中岩大地原/调整分红](docs/research/zhongyan-2025-dividend.md) 与 [江波龙合并分红精度](docs/research/jiangbolong-2026-joint-dividend.md)，原始保存不等于相应账本已开放。

市场统计的完整日、缺值、停牌、当前类型与版本口径见 [市场概览说明](docs/market-summary.md)。

资料表支持展开中文字段、单位口径和官方来源；空值、原始比例与未知单位的处理见 [字段说明](docs/data-fields.md)。

日线复权图表在完整因子区间上按官方累积因子展示，并标明固定因子版本；覆盖不足时明确提示连续价格的不同归一基准。官方前后复权样本单独保存，真实六股对照与回测信号边界见 [复权说明](docs/adjustment-data.md)。

完成报告可切换日末/分钟回撤曲线，并选择证券在行情页查看固定报告数据版本的买卖点；坐标、复权价格和分钟时刻口径见 [报告图表说明](docs/report-charts.md)。

首笔开发期 `cash-ledger-0.1.0` 报告保留阅读和导出，没有完整引擎归档，因此不显示原版本重算入口。后续报告保存模型、引擎、数据版本及依赖环境的冻结引用。

ETF 日线及四种分钟示例在 `strategies/ma_cross_etf` 与 `ma_cross_etf_5/15/30/60`。510050/510300 按独立产品规则执行；正式公告权益作为补充来源保存在 PostgreSQL，资料页和报告均区分来源。新环境导入、范围和账本证据见 [ETF 使用说明](docs/etf-backtest.md)。

额外财务示例在 `strategies/ma_profit`：均线趋势成立且最新已可用报告的 EPS TTM 高于门槛时持有。先采集 `profit` 所需季度，再在回测研究页选择“盈利过滤 · 趋势示例”；报告可查看每次信号传入的财报和公告日期。规则及实际公告边界验收见 [财务策略说明](docs/financial-strategy.md)。

财务与宏观表采用官方中文字段名，保留来源原值；不同接口的百分数与小数比例不统一转换。单位与缺失处理见 [字段口径](docs/field-values.md)。

宏观资料显示固定版本的全量数值覆盖、来源末期与各字段最近有效数值期；五类当前仅供浏览和导出，日期与历史版本边界见 [宏观说明](docs/macro-data.md)。

A 股日线副图支持四种来源估值比值，缺值断开、复权价格不换算估值，见 [估值曲线说明](docs/valuation-charts.md)。数据中心的 26 方法逐项区分采集、来源覆盖与历史用途，见 [接口支持矩阵](docs/interface-support.md)。

模型入口类接受参数字典，实现 `on_bar(context)` 并返回 `{完整证券代码: 0到1的目标权重}`，合计不超过 1；上下文包含截止模拟时刻的行情窗口、账户、已有目标及声明的财务数据。接口版本 1 支持日/周/月以及 5/15/30/60 分钟信号：日周月采用下一日开盘，分钟采用下一 bar 开盘近似。周月示例目录为 `strategies/ma_cross_w`、`ma_cross_m`，分钟为 `ma_cross_5/15/30/60` 对应目录；源数据不足时先在数据中心补采。清单、时点/缺失政策和完整输入见 [策略契约](docs/strategy-contract.md)。包内相对导入和回调时辅助导入可用，独立进程不是安全沙箱。

市场页可按 PE/PB、成交额、行业筛选和排序，保存条件并下载 JSON；导出保留所选保存记录，未保存修改需先保存，见[筛选导出说明](docs/market-filter-export.md)。数据中心可配置本机定时同步。全市场日线独立更新，财务/公司行动/多周期按配置与自选合并后的证券范围更新。工作进程停机时不运行，日线、证券池、指数及分钟按各自已发布水位补跑，每轮从最早欠缺日起最多生成 100 日任务；分钟水位按证券与频率分别计算。首次没有水位仅取最新就绪日，更早历史与水位之前的缺口使用区间回填；失败任务保留并手动重跑。源就绪时间与实际覆盖均可查看。

回测页的“分段参数研究”先填写三个不重叠区间和候选参数数组，使用左侧模型、股票池、资金与费用。提交时一次固定数据/模型/引擎版本；全部训练和验证完成后，锁定一组参数才产生样本外任务，锁定后不能更换。每段独立初始资金、不继承前段持仓；历史已被看过或反复另建研究时，不能再称它是未参与调参的独立样本外数据。每组任务仍支持日志、取消、原清单重跑与报告导出。 当前引擎五个真实分段任务的固定版本和锁定边界见 [参数研究验收](docs/verification-current-parameter-research.json)。历史运行每页20条，可翻页访问全部保存的报告，跨页选择仍可用于比较。

多年日线回填会产生较长任务，历史成员模式要求区间逐日证券池齐全，结束日模式只用结束日名单。完成 100 项或本段经过一分钟后，在完整操作提交边界保存检查点、让出唯一采集通道十秒，再自动继续；单项操作可能超过时间阈值。一小时预算仍提供兜底暂停。接收中断最多三次退避，每日预算达到后次日续跑，取消/失败不会把部分分页发布为完整数据。取消和按检查点重跑入口在数据中心。

数据中心的任务列表始终显示活动任务，历史任务每页20条；选中任务后，日志从新到旧每页100条，可翻查全部保存记录。翻查历史任务不会隐藏活动采集，也不会自动取消或重跑。已完成历史池任务1135条日志的全量核对见 [任务/日志分页验收](docs/verification-job-log-pagination.json)。

仅修改 API/页面后的后端重载入口为 `scripts/restart-api.ps1`；工作进程或迁移变更使用正常停止/启动入口。前端源修改后需要重新构建。

## 当前回测口径

经典双均线示例采用短期/长期均线，目标变化后下一交易日开盘执行，持股期间不每天强制再平衡。费用、滑点、成交量假设在运行清单中固定。证券成交只使用原始价格；信号连续价格按已结束行情的前收盘基准构造；现金分红独立入账。

送转除权日会按已知开盘价格与含权益净资产重新计算跨日目标数量；报告可查看原数量和调整依据。未到上市日期的股份不能卖，未到付款日期的现金保留为应收，部分订单剩余到期不追单。真实日/分钟及独立恢复副本日期验收见 [送转股说明](docs/research/bonus-shares.md)；小数股结算仍不猜测执行。

当前开放 2023 年以来沪深主板 A 股日/周/月及四种分钟信号；科创板与创业板股票规则支持 2023-01-01 至 2026-10-09，已核算日线和通过来源交叉核对的四频率分钟样本，两板周/月经典样例已核算；真实跨分红分钟及更多特殊事件仍需扩大验收，见[两板回测说明](docs/growth-board-backtest.md)。已核验 ETF 范围及独立费用/权益见 ETF 使用说明，其它 ETF 类别需继续核验。分钟报告可切换分钟净值、读取分钟现金/持仓与完整时间明细；年化和基准仍用日末采样。来源分钟极值未完全覆盖日线极值的差异逐项披露，不能验证真实触价/止损成交，详见[分钟说明](docs/research/minute-clock.md)。开收盘或量额口径尚未核验的历史分钟样本仍拒绝；这个严格门槛不等于官方承诺分钟与日线同源无损聚合。印花税按 2023-08-28 前后处理，佣金/过户费为用户选择配置，分红税采用明确的固定比例假设。主板风险警示/IPO 初期及缺失必要行情继续拒绝；两板 IPO 前五日按完整交易日历判断。

初次开发验证运行不代表整个计划已经验收。数据源回溯修订、源覆盖缺失、历史信息时间和 OHLC 成交近似仍须结合报告说明理解。
