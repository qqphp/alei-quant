# 宏观资料的覆盖与历史使用

数据中心可以浏览及导出五类 BaoStock 宏观原值。选择宏观数据集会清空证券代码；点击“读取本地数据”后，页面显示固定本地版本、全部记录数、来源末期、日期异常字段数，以及每个指标的有效数值、空值、非法数值、有效零值和最近有效数值期。统计覆盖全部记录，不只当前一页。

切换数据集或编辑证券代码会清空上一次结果与分页版本；迟到的其它查询响应不会覆盖当前选择。连续分页保持已加载的固定版本。原始 JSON 行及全部 CSV 仍保留来源字段和值，覆盖说明另置于 API 的 `historical_support`，不向原值添加模拟发布时间。

## 当前支持范围

五类均标记“仅供浏览 / 导出”，不能声明为回测模型的必要数据。它们不是财报公告时钟的简单复用；依据和官方链接见[宏观历史可用研究](research/macro-availability.md)。

| 数据族 | 日期依据与实际限制 |
|---|---|
| 存款利率 | 官网将 `pubDate` 称为发布日期，但两个已核对的央行事件显示源日对应生效日；不能把全部源日当成可靠公告时钟。当前 43 行截至 2015-10-24，不表示今日银行利率。 |
| 贷款利率 | 同样 43 行截至 2015-10-24；历史基准、公积金利率不是 LPR 或今天的贷款报价。 |
| 准备金率 | 公告与生效分别保留；生效前的 After 是已公告调整目标，不是已经实施的状态。47 行公告止于 2018-06-24，最后生效日 2018-07-05，不能无限延伸为今日有效政策。 |
| 月度货币量 | 只有统计年月，没有发布时间/历史发布版本。441 行止于 2026-09，但该月九个指标全部空；最近有效指标期为 2026-08。不能按月末或固定延迟制造历史可用时点。 |
| 年度货币量 | 35 行 1990–2024，只有统计年；年底余额不是年内已知值。 |

央行原始资料显示 M1 口径存在后来回溯修订。固定本地版本只能复现本次采集值，不能证明当年首次发布原值；本地抓取/发布日也不是宏观历史公告日。政策记录可能适合另行限定的事件研究，但开放前须明确公告/生效语义、历史版本证据及完整覆盖，不能改变当前正式回测权限。

## 实际验收

固定版本 21049，五类共 609 条真实原值（43+43+47+441+35）的全部分页、完整 CSV 和数据库原值相等。每个指标的全部计数、最近有效数值期、日期范围逐项独立计算相等；五种宏观模型声明均拒绝并给出用途说明。非法日期、非法月份、NaN、空值、合法零及空序列仅在内存构造核对，没有 SDK 调用或主库模拟写入。见 `verification-macro-support.json`。

浏览器实见月度 441 行、来源末期 2026-09 与最近有效期 2026-08 的区别；第二页保留版本与全量统计。切换准备金清除旧行/版本并恢复第一页，公告末期与生效日期分开显示。实际从最新生产页面下载版本 21104 的月货币量 CSV，45,708 字节、441 行，与 HTTP 文件和全部原值相等；控制台 error/warn 为空。截图 `screenshots/macro-support.png`。TypeScript/生产构建通过，仍保留既有大包提示。
