# 复权价格与回测价格

复权对照数据单独保存为 `reference:bars:d:1`（官方后复权）与 `reference:bars:d:2`（官方前复权）。未复权行情继续保存在 `bars:d`，最新报价投影和回测撮合只读未复权数据。参考序列可通过固定版本的数据集 API 分页读取与 CSV 导出，不是策略可声明的数据族。

采集通过已有串行通道、每日请求预算、完整分页、就绪时间和持久检查点执行。`query_history_k_data_plus` 的标记 1/2 只允许日线，要求日期、代码、OHLC 和复权标记；返回标记必须与请求一致。异常 OHLC、未就绪和同键冲突不能发布，重复原值不产生新修订。

回测 `signal_close` 使用固定版本最早行情归一的涨跌幅连续序列，之后只根据已经结束的日线前收盘参考价更新。它不读取最新前复权样本；成交、账户估值和公司行动现金流仍按原始价格处理。

图表在有完整区间的历史因子查询、且第一根行情之前已有因子时，读取该查询批次的固定因子版本，逐日将原始 OHLC 乘以最近已生效的 `foreAdjustFactor` 或 `backAdjustFactor`。官方后复权沿用上市基准；官方前复权沿用来源批次的最新归一，缩小图表区间不会改按所选结束日重新归一，因此可包含区间之后的事件，仅供展示。MA 与 MACD 按当前展示价格计算，成交量不复权。

缺少完整区间因子时，图表保留涨跌幅连续序列，并明确提示绝对价格不等同官方复权：后复权以最早已入库行情为基准，前复权按所选结束日归一。非日线继续只支持原始行情。未知或非正因子停止展示，不能静默补 1。

官方本地计算示例的注释与代码不一致：注释写除以因子，代码实际相乘；字段表的比例描述也不足以解释实际累积因子。实测应按交易日取最近一条已生效因子，不逐条连乘 `adjustFactor`，不能将最新前复权展示价格直接用于历史绝对价格阈值策略。

真实对照任务 `0d00d613-2a36-4749-a7c9-902826adacc3` 完成 18/18 项，包含浦发、平安、茅台、四川路桥、禾川和特锐德从上市以来的因子，以及 2023-01-01 至 2026-10-09 的官方前后复权各 910 根日线，共 10,920 根、43,680 个 OHLC 值。原始价格 × 最近已生效累积因子与官方值按 Decimal **精确相等**，原始成交量/金额/交易状态/ST 字段保持。固定版本 HTTP/CSV、按来源字段顺序重建的 SHA256、完整和短区间图表、旧备份的连续信号逐项核对通过。图表为浮点数，数值比较使用 1e-14 相对或 1e-10 元绝对容差，不改写源值。

旧连续前复权与官方收盘的最大差异在这些样本中为茅台约 0.00084413 元，保留在证据中；该近似连续尺度适用于既有信号语义，不声称与官方绝对复权值完全相等。官方因子按返回值累积，不依据含糊的字段文字逐项连乘；上市初始因子也作为返回的真实记录保存。

重复任务 `752fff34-c568-476f-81ee-e3fb28889a8c` 同样完成 18/18 项，全部批次的新值数为零。页面实见官方后复权图表、因子版本和口径说明，控制台 error/warn 为空；TypeScript 与生产构建通过，主脚本约 756.30 kB，仍有既存大包提示。
