# 阿雷红变策略、阿雷绿变策略与 RVC001 副图

当前启用“阿雷红变策略”1.1.0、“阿雷绿变策略”1.0.0。红变1.0.0已停用新回测入口，旧报告可读取和按原版本重算。在策略模型页可直接配置回测，频率为日线，默认总目标仓位95%，按固定候选股票池等分。固定 EMA3/EMA8，不额外开放周期参数。首次回调不因已经处于红K而建仓，必须出现新的金叉。

| 模型 | 入场 | 出场 |
|---|---|---|
| 阿雷红变策略 | FAST>SLOW 且上一根 FAST≤SLOW | 持有后首次粉K或绿K：PINKK 或 GREENK |
| 阿雷绿变策略 | FAST>SLOW 且上一根 FAST≤SLOW | 持有后首次 FAST<SLOW 且 FAST≤上一根 FAST |

红变遇到粉K或绿K清仓；绿变经过粉K仍持有、直到首次绿K清仓。两套策略在红K、蓝K时继续持有；持有中忽略重复金叉，出场后等待新的金叉，不每日再平衡。预热不生成交易，回测开始时空仓。清单预热11根，信号完成后下一交易日开盘成交，成交约束、费用、部分成交与期末估值继续沿用平台。

## 副图及价格

市场行情的副图选择器新增“RVC001 四轨道趋势”。从两个新模型的报告点击“在行情页查看买卖点”时，自动选择此副图，并保持报告的数据版本和日期区间。

日线副图使用平台连续信号价：按已结束日线的前收盘参考价递推比例，OHLC 使用相同比例换算。主图原始/前复权/后复权切换不会改变副图数值。两图价格轴可以不同；副图提示显示信号价，主图成交点保留原始成交价。其它六个周期使用该周期原始信号价格，只有日线提供这两个回测模型。

EMA 以固定版本最早可用收盘价初始化，递推系数为2/(N+1)；先计算完整前缀，再截取显示区间。四轨道为 EMA10±STD10、EMA10±2×STD10，STD 使用样本标准差（分母9），前9根轨道为空。初始一根没有 REF 值，不产生颜色状态或交叉信号。从第二根开始，四种状态严格使用原公式条件；蓝色 `COLORFF8800` 转换为网页 RGB `#0088ff`。参考[通达信函数说明](https://help.tdx.com.cn/gspt/docs/markdown/redword/functionlist.html)。

红箭头标记原金叉；粉箭头表示红变在粉K出场，绿箭头表示相应策略在绿K出场。同根绿K触发两套规则时只显示一个绿色箭头，提示列出“阿雷红变、阿雷绿变”。白色小三角保留原公式死叉，与同根绿色箭头错开。两套信号状态从请求的开始日期空仓计算，截断显示数量不重置状态。开始日期改变后出场标记可能变化，EMA、轨道、颜色和原交叉条件保持相同。箭头是信号，实际模拟成交仍在主图和报告显示。

## 接口与归档

策略接口仍为v1，日线历史增加 `signal_ema3`、`signal_ema8`；两个模型通过冻结引擎中的 `stockapp.rvc001` 读取同一计算和出场规则。红变1.1.0需要 `cash-ledger-0.13.1` 中的多颜色出场支持；绿变仍可使用原单颜色调用。模型不能单独运行于没有此模块的旧引擎。

行情 API 路径不变，每根 `rvc001` 包含信号 OHLC、fast/slow/mid/sd、up/down/up1/down1、state、buy/down_cross/red_exit/pink_exit/green_exit。`red_exit` 是红变任一种颜色的出场，`pink_exit` 是红变在粉K出场，`green_exit` 是绿变出场。响应包含 `rvc001_note` 和 `rvc001_red_exit`。

可选查询参数 `rvc001_red_exit=pink|pink_or_green`，默认 `pink_or_green` 使用新红变规则。查看原 `cash-ledger-0.13.0` 报告时，页面自动传入 `pink`，保留原红变仅粉K出场的标记。原始报告继续引用自己的模型、引擎、数据与完整清单；新运行引用0.13.1归档。

## 验证

25项离线回归通过，包含红变直接遇绿K、蓝K后遇绿K、粉K出场、绿变连续粉K持有、清仓后不重复卖出、旧单颜色调用、API参数与新旧副图模式，以及原公式和窗口/复权一致性。真实三股示例池、固定数据版本33943、2024-06-01至2026-10-09：两个新运行各570个信号日，红变、绿变各206笔模拟成交；订单信号与下一交易日执行已核对。

两个新运行的冻结版本重算与导出完整一致；原0.13.0红变/绿变和0.12.1经典策略报告的清单及结果重算一致，旧副图全部原字段及出场标记也与原归档公式相等。证据见 [1.1验证记录](verification-rvc001-v1.1.json)，原版验收保留在 [1.0验证记录](verification-rvc001.json)。复验入口为 `scripts/verify-rvc001.py`，使用本机原版回执和已入库行情，不调用行情SDK或写入模拟行情；它会创建本地回测及重算记录。

前端函数已核对1710根真实K线、389个标记，其中23根绿K同时触发两套策略出场并共用一个绿色箭头。运行上述复验入口产生前端输入后，可执行 `node scripts/verify-rvc001-chart.cjs`，核对颜色、轨道、共用绿色箭头、两套出场提示及旧规则标签。生产构建通过，保留原有的大包提示。

浏览器实见新版报告使用粉/绿出场，2026-08-27绿色箭头提示同时列出“阿雷红变、阿雷绿变”；原88b8ee20报告仍显示“旧版红变出场：首次粉K”。控制台无 error/warn。截图见 [新版模型](screenshots/rvc001-v1.1-models.png)、[新版副图](screenshots/rvc001-v1.1-chart.png)、[共用绿箭头](screenshots/rvc001-v1.1-green-exit.png)。原版七周期及截图证据仍对应1.0验收。
