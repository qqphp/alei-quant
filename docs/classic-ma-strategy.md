# 经典双均线示例

## 依据与用途

短期简单移动平均线（SMA）上穿长期 SMA 产生做多信号，是常见的均线交叉方法。方法说明参照 [Fidelity 的 SMA 指标说明](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/sma)，查阅日期 2026-10-10。以下参数、仓位和成交政策是本平台的示例选择，不是该来源推荐的收益最优配置。

本地实现为 `strategies/ma_cross/strategy.py`，安装清单为同目录 `manifest.json`。仅使用已结束日线的连续收盘价格计算信号，原始价格用于成交和账户记账，分红独立计入现金流。

## 精确规则

| 项目 | 示例约定 |
|---|---|
| 默认参数 | 短期 10 日、长期 30 日、总目标仓位 95%；允许修改，短期必须小于长期 |
| 均线 | 最近 N 个交易日 `signal_close` 的算术平均；不含未来行情 |
| 买入信号 | 当日短均线大于长均线，前日短均线小于或等于长均线 |
| 卖出信号 | 当日短均线小于长均线，前日短均线大于或等于长均线 |
| 区间首日 | 若短均线已高于长均线，则初始化为持有目标；这是本例明确加入的初始化政策 |
| 均线相等 | 保留此前目标，不产生额外交易 |
| 股票池与资金 | 固定用户股票池；每只分配 `exposure / 股票池数量`，没有信号的份额保留现金，不在活跃股票间重新分配 |
| 成交时点 | 信号后的下一交易日开盘；单笔订单当日有效，剩余部分到期撤销 |
| 持有与失败订单 | 目标未变化时不每日再平衡；拒绝或部分成交后也不会自动追单，直到下一次目标变化 |
| 预热 | 清单固定 251 根历史窗口以支持最长 250 日均线；引擎要求开始日前有完整预热日历和行情，预热期不交易 |
| 账户 | 做多现金账户；当前执行范围含 2023 年以来已核验的沪深主板、科创板及创业板股票；两板当前核验窗口截止 2026-10-09，规则见 [两板说明](growth-board-backtest.md) |

手续费、滑点、前一交易日成交量参与上限、T+1、涨跌停和公司行动处理由运行清单固定。最后一天的信号不使用区间外价格成交；期末持仓按收盘价估值。

## 周线与月线示例

`strategies/ma_cross_w` 默认短/长均线为 10/30 周，61 根预热；`strategies/ma_cross_m` 为 3/6 月，13 根预热。它们使用相同交叉逻辑，只改变频率、参数范围和窗口。参数是功能示例，没有按历史收益择优。

策略只收到已就绪的官方周期行情，连续信号收盘价取该周期末已结束日线的连续价。周六 17:30 或次月 1 日 17:30 才决策；每日现金、分红、持仓、费用和净值仍使用日线处理，下一可用交易日开盘执行。完整日线和官方周/月线两者都必须覆盖；缺少完整周期或来源价格/量异常时停止，不自动换成派生周期。

开始日至首次就绪信号之间保持现金；月线的首个信号可能晚于开始日数周。周月原始金额与日线汇总的细小差异按明确的 1 元容差记录；来源值不改写。详细契约见 `strategy-contract.md`。

## 阅读结果

分钟示例目录为 `strategies/ma_cross_5`、`ma_cross_15`、`ma_cross_30`、`ma_cross_60`，默认 10/30 个对应周期 bar、61 根预热。使用相同交叉逻辑，下一 bar 开盘模拟执行，T+1 仍按交易日处理；分钟信号不会使当天买入股票变成可卖。报告可切换分钟收盘净值和日末基准，订单显示完整信号/执行时刻。来源差异和模拟限制见[分钟时钟说明](research/minute-clock.md)。

初始三只股票为浦发银行、平安银行、贵州茅台，是人工选定的功能样例。已完成的 2024-06-01 至 2026-10-09 运行有 570 个交易日、78 笔成交，总收益约 -16.08%，最大回撤约 20.90%。它证明该输入下采集、模型、执行、报告流程可以运行，不证明策略具有稳定收益。

均线对价格变化存在滞后，震荡区间可能频繁交叉；改变参数需要单独保留训练、验证及样本外区间。报告的固定股票池、当前回溯财报和 OHLC 成交近似限制继续适用。不要把全区间参数最高收益作为样本外结论。

## ETF 对应示例

`ma_cross_etf` 和对应 `_5/15/30/60` 包沿用相同 10/30 交叉逻辑，最大长均线 30、31 根预热，匹配较短来源历史；原股票日线 251 根模型仍为默认。产品交易、T+1、三位报价和公告权益由引擎按已核验规则执行，详见 [ETF 使用说明](etf-backtest.md)。
