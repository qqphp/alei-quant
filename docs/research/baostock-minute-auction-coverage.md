# BaoStock 分钟线、集合竞价与全日行情的覆盖边界

核验日期：2026-10-10。仅阅读官方网页、官方发布的 Python SDK 源码与交易所正式规则；未调用 BaoStock SDK，未修改代码、数据库或采集任务。

## 结论

**本次核对的 BaoStock 官方资料没有明确说分钟线排除开盘集合竞价，也没有明确承诺首根分钟 `open` 等于日线 `open`、分钟成交量/额之和等于日线总量/额。** 同样，没有找到官方条款明确把这些差异宣布为正常或给出容许误差。两种断言均超出已核验资料。

交易所规则提供一项可以确认的覆盖差别：科创板、创业板均有 **15:05–15:30 盘后固定价格交易**，其成交量、金额在盘后结束后计入股票当日总量、总额。因此仅覆盖至 15:00 的分钟序列，与交易所全天统计不是天然相同的统计范围。但是 BaoStock 是否按此方式构建日线、实际个股差额是否来自盘后，仍需独立数据证明，不能由规则直接推出。

## BaoStock 的明确说明与未说明部分

本次重新通过官网前端实际使用的 Markdown 接口读取并保存完整 `stockKData.md`、`home.md`、`modifyRecord.md`。网页壳是动态页面，不能把网络工具只读到的空正文当作完整资料；保存的是官网接口返回的原 Markdown。

| 项目 | 官方明确说明 | 此次未找到的承诺 |
| --- | --- | --- |
| 周期 | 日、周、月及 5/15/30/60 分钟 | 日线由这些分钟线同源、无损聚合而成 |
| 分钟时间 | `time` 格式 `YYYYMMDDHHMMSSsss` | 字段是窗口开始/结束、左右端点开闭、09:25 撮合归属哪根 bar |
| 分钟价格 | OHLC 为人民币元，标注四位小数精度 | 第一根 open 必然是全日第一笔成交价 |
| 分钟量额 | volume 单位股、amount 单位人民币元；按所述时间范围累计 | 分钟覆盖全部竞价、盘后及大宗成交；与日线逐项守恒 |
| 日线 | open 为当日开盘价格，volume 单位股，日线字段含停牌状态 | 同一事件在各频率的清洗、修订及汇总机制相同 |

字段和参数来源：[BaoStock 官方 K 线文档](https://www.baostock.com/mainContent?file=stockKData.md)。官网还分别列出日线 17:30、分钟线 20:00 入库时刻；这说明发布时钟分开，不说明行情统计口径一致或不同。[平台介绍](https://www.baostock.com/mainContent?file=home.md)。

官方 K 线文档谈到不同系统复权算法可能导致差异，但不能用该说明解释两份均为 `adjustflag=3` 的日线/分钟差异。原始不复权字段、周期、版本、分页完整性、整数成交量转换应先核对；不能先把差异归为复权或浮点舍入。

官网数据调整记录列有历史日线异常修复、分钟缺失补充等条目，未列本任务 2024-06-11 至 19 的禾川科技/特锐德差异说明。这只证明官网公开修订记录中存在修正历史，不能证明本次数据已错、已修复或已被保证正确。[官方数据调整记录](https://www.baostock.com/mainContent?file=modifyRecord.md)。

## 官方 SDK 能证明什么

核对 [BaoStock 0.9.4 官方 PyPI 发布](https://pypi.org/project/baostock/0.9.4/)的源码包，实际下载并核验 PyPI 公布的 SHA-256。以下三份源码与本地安装字节完全一致：

- `baostock/security/history.py`：`query_history_k_data_plus()` 对参数做检查，把字段、日期、周期、复权标志送到服务器，再读取返回的记录和字段；没有本地逐笔→分钟或分钟→日线的聚合算法。
- `baostock/data/resultset.py`：解析响应 JSON 的 `record`，处理翻页及行访问；没有以成交时刻过滤竞价的实现。
- `baostock/demo/demo_A_stock_5mk-data.py`：分钟样例请求与输出流程；没有竞价口径、全天守恒断言。

因此 SDK 源码不能揭示服务器的行情采样、竞价归并、盘后纳入、数据供应商或更正机制。没有这类本地实现，不等于已经证明服务器排除竞价。

## 2024 年样本对应的交易所规则

使用 2023 年修订正式规则分析 2024 年样本；不把 2026 年新规则倒用于 2024 年。原件已经本地保存，本轮重新核验其 SHA，详见证据清单。

### 开盘和竞价

- 上交所 2023 规则第 4.1.1–4.1.2 条、深交所第 4.2.1–4.2.2 条：当日开盘价是第一笔成交价，先通过集合竞价形成；未能形成时再由连续竞价形成。
- 两所竞价交易时段第 2.3.2 条区分 09:15–09:25 开盘集合竞价、09:30–11:30 和 13:00–14:57 连续竞价、14:57–15:00 收盘集合竞价。科创板和创业板均不能把整个 09:30–15:00 简称为纯连续竞价。

来源：[上交所 2023 正式规则原件](https://www.sse.com.cn/lawandrules/sselawsrules2025/repeal/rules/c/10824490/files/dcbe58edb194451d93f19b1f7dd8fb4c.docx)、[深交所 2023 正式规则原件](https://docs.static.szse.cn/www/lawrules/rule/repeal/rules/W020230217564423808793.pdf)。

**推断边界：**若一个行情产品的首根窗口只纳入 09:30 之后成交，该窗口 open 可能不同于 09:25 开盘集合竞价价；这与交易时段规则相容。然而 BaoStock 文档没有确认其首根窗口只包含这些成交，所以不能把禾川实际差异标注为“已证实缺少集合竞价”。也不能由最后 bar 时间 15:00 证明它必然包括或排除收盘集合竞价。

### 全日成交量包含不同交易渠道

| 市场 | 盘后固定价格交易规则 | 纳入全日总量/额 |
| --- | --- | --- |
| 科创板 | 上交所 2023 第 6.2.2 条，15:05–15:30，按收盘价撮合 | 第 6.2.10 条，盘后结束后计入 |
| 创业板 | 深交所 2023 第 3.6.1–3.6.2 条，15:05–15:30，按收盘价撮合 | 第 3.6.9 条，盘后结束后计入 |

此外，上交所第 3.6.12 条、深交所第 3.5.11 条规定大宗成交不纳入即时行情与指数计算，成交量在大宗结束后计入当日证券成交总量。它是另一项不能忽略的渠道范围区别；不能把所有差额都直接算作盘后固定价格成交。来源同上两所正式原件。

**推断边界：**若 BaoStock 日线承接全天总量、分钟仅承接截至 15:00 某类竞价量，正的日线−分钟差值可与额外渠道成交相容。若存在负差值、时间窗口重叠、不同频率汇总不一致，则这个假设不足以解释。即使差量对应差额/收盘价，也仅是数值相容，尚须官方逐日盘后、大宗数据或数据源口径确认才能归因。

## 对当前平台的建议

父任务报告 2024-06-11 至 19、`sh.688320` 与 `sz.300001` 的四种频率已经采完，并观察到禾川首根 open 差异、特锐德量差。本轮未读主库逐行数据或复核具体数值；这些是研究输入，不是本文件对数据完整性的独立验收。

1. 将“来源分钟线”作为独立历史行情序列，明确模拟窗口、执行价格和已结束 bar 的量额；不要冒充完整全天逐笔重建，也不要用日线量补造某根分钟成交量。
2. 单根 OHLC 自洽、非负量额、代码/复权/日期正确、唯一时间与本平台窗口完整性仍应核对。48/16/8/4 根是本平台窗口契约，不是本次找到的 BaoStock 官方覆盖保证。
3. 日线/分钟开盘及量额不同应原值逐项留档，并显示未解释的来源口径差异。若业务选择继续回测，应把这一许可作为明确的模拟范围政策；不能写成“BaoStock 官方允许差异”或仅为使样本通过而提高数值容差。
4. 若策略需要准确参与开盘集合竞价、全天成交量因子或盘后成交，需要来源明确口径或补充可核对的数据。分钟内止损、触价与队列成交不能由 OHLC 推出。
5. 现行“分钟之和必须等于日线”的强校验不是上述官方文档给出的普遍保证；可作为平台选择的严格门槛，但应区分范围不相等与数据错误。是否调整门槛由父任务基于实际源证据、模拟目标与用户要求决定，本研究没有变更它。
