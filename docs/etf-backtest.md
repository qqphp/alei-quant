# ETF 回测使用与来源口径

当前引擎：`cash-ledger-0.10.2`。首批开放 `sh.510050`、`sh.510300` 两只已核验国内股票 ETF，来源核验区间为 **2026-01-05 至 2026-10-09**。其它 ETF、区间外事件与完整市场覆盖仍需扩展和验收，不能由两个样例推断全部支持。

## 使用

1. 在数据中心采集所选 ETF、基准、交易日历及足够的日线/分钟预热；来源从 2026-01-05 起，不伪造更早行情。
2. 选择“ETF 日线示例”或对应 5/15/30/60 分钟示例，证券池填完整代码。日线示例默认 10/30、31 根预热，长均线最大 30、短均线最大 29。原股票日线模型仍为 251 根窗口，仍是默认模型。
3. 填写区间、资金及综合佣金。ETF 二级交易不使用股票过户费率和固定股息税，报告列明实际规则；佣金含规费，最低额按用户合同配置。
4. 报告可查看三位小数成交价、现金/应收/可卖数量、公告来源及原件摘要；资料页“分红送转”另列正式公告补充权益，数据中心可读取/导出 `official_actions`。

新环境的正式公告导入是一次显式本机步骤，原件须位于 `docs/research/510300-202601-dividend.pdf`：

```powershell
$env:PYTHONPATH = "$PWD\backend"
.\.venv\Scripts\python.exe -c "from stockapp.asset_rules import import_announcement; print(import_announcement())"
```

该操作核对原件 SHA256，将已人工核验条款作为 `official_actions` 发布到 PostgreSQL；重复导入相同内容不产生修订。不是 BaoStock 接口，也不联网采集其它来源。当前已发布版本为 8773；条款随数据库备份、原件随文档备份保存。

## 交易与账户

| 项目 | 当前规则 |
|---|---|
| 成交价 | 0.001 元档位，滑点及涨跌停按该档位四舍五入；现金和手续费按分币处理 |
| 数量 | 买入 100 份整手；清仓可卖出全部零散余额；每笔超过 100 万份明确拒绝，不模拟拆单 |
| 结算 | T+1；分钟信号不改变当日买入不可卖；失败订单不自动追单 |
| 价格边界 | 两只对象按普通基金 10%；开盘涨停不买/跌停不卖是平台保守近似 |
| 费用 | 配置综合佣金；无二级份额过户费及证券交易印花税，不重复扣经手费或基金内部费用 |
| 信号/执行 | 仅已完成 bar 发信号，下一原始开盘成交；容量使用前一已结束 bar/交易日的量 |

官方依据见[核验记录](research/etf-rules.md)。ETF 返回中的 `isST` 不作股票风险警示解释；源值保留。指数仍只作基准，不作可买卖证券。

## 正式公告权益

510300 的 BaoStock 分红、因子返回空，但[正式公告](https://www.sse.com.cn/disclosure/fund/announcement/c/new/2026-01-12/510300_20260112_VTCZ.pdf)记载每份派现 0.123 元，2026-01-16 登记、19 日除息、27 日现金派发，分配收入暂不征税。登记日买入并持有至收市获得权益；除息日才买不获得此前登记权益。

19 日确认应收，27 日才转为可用现金；期间卖出仍保留已取得应收。23/26 日内部划款不作账户到账日。条款、来源类型、原件摘要、规则和数据版本固化到每次运行，重算不读取随后修订的当前记录。

报价参考价用于检查事件缺口：即使空仓，预热/回测窗口内未知除权变化也停止报告。不从价差猜测登记、派息、实派金额或税率；未知份额折算继续停止。标题检索和参考价检查不能保证来源未披露的其它事件，覆盖等级随报告保留。

## 日收盘与分钟末价

2026-07-06 前沪市基金官方日收盘按末一分钟成交量加权确定，可以不同于分钟末价；后续采用收盘集合竞价。依据：[2023 版规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/repeal/rules/c/10824490/files/dcbe58edb194451d93f19b1f7dd8fb4c.docx)第 4.1.3 条、[2026 版通知](https://www.sse.com.cn/lawandrules/sselawsrules2025/fund/trading/c/c_20260424_10817739.shtml)。

平台仅对已核验产品、旧规则日期、官方日收盘位于最后 bar 范围内的差异保留两种原值；其它冲突或量/边界缺口仍停止。来源尚未逐笔证明样本差异的具体计算过程，不声称已从 OHLC 重建末一分钟加权收盘。

分钟信号/净值用分钟价；日末估值、年化、Sharpe 和日末基准用官方日价，两种净值可能略有不同。差异明细与警告导出，不改写价格让曲线相等。

- 四个日线/分钟原归档重算的完整结果严格相等。[重算证据](verification-etf-replays.json)。
- 备份 `runtime/backups/20261010-150920-233570` 已恢复到独立验证库；官方公告版本 8773、原件摘要、日线分红与旧规则分钟重算保持一致，新规则分钟也由恢复程序完成重算。[恢复证据](verification-etf-restore.json)。最后的公告中文列名与 CSV 字段/零值导出修复在该快照之后。
- HTTP 拒绝未知 ETF 和超出核验区间的请求，不创建运行；固定版本公告 CSV 全字段及数值零保持。[接口证据](verification-etf-api.json)。
