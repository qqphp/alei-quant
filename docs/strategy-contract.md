# 本地策略接口 v1

仅安装自己信任的本地 Python 目录。安装时检查清单、入口类、已安装依赖和参数，不执行策略；运行时使用独立进程。这不是未知代码的安全沙箱。

## 最小包

参考 `strategies/ma_cross`：`manifest.json` 加 `strategy.py`。入口类接收已校验的参数，`on_bar(context)` 返回 `{证券代码: 目标权重}`，做多现金账户权重合计不得超过 1。省略代码代表目标权重 0；目标变化才生成下一交易日订单。

`frequency` 支持 `d/w/m/5/15/30/60`，`lookback` 为 1–10000 的对应周期窗口长度。清单须声明与频率一致的 `bars:频率`；不支持把其它频率同时声明为策略历史。参数类型支持 `integer`、`number`、`boolean`、`string`，每项有默认值，可声明数值范围或枚举。包内依赖只允许已安装的包与版本约束；运行中不联网安装。

入口也可为 `signals/strategy.py:Strategy` 等包内路径；根目录存在 `__init__.py` 时按真实包初始化，支持包内相对导入与回调时才导入的辅助模块。每个回测在独立进程中载入固定摘要的归档目录，包路径在回调期间保留。最小单文件示例无需添加 `__init__.py`。

## 时点与输入

| 输入 | 内容 |
|---|---|
| `date`、`signal_at`、`frequency`、`codes` | 信号就绪的上海日期/完整时刻、声明频率、运行时固定股票池 |
| `valuation_date` | 信号时点前最近已结束交易日；账户估值与财务可见性使用该日 |
| `history[code]` | 截止信号时刻已经就绪、长度不超过 lookback 的对应周期行情；原始价格和仅使用已结束日线构造的连续信号收盘价格 |
| `history[code]` 的 `signal_ema3`、`signal_ema8`（日线） | 从固定版本最早可用连续信号价递推的 EMA3/EMA8，不随滑动窗口重置；RVC001 使用冻结的固定公式模块，红变1.1.0的粉/绿出场需要引擎0.13.1，详见 [RVC001](rvc001.md) |
| `account` | 现金、应收分红、净资产、总持仓及 valuation_date 当日可卖数量；日内市场单无跨日现金预留，`frozen_cash=0` |
| `targets`、`first_signal` | 前次目标权重、是否首个信号日 |
| `seed`、`rng` | 固定平台种子、每次运行独立的 NumPy Generator；启动时还初始化 Python random 与 NumPy 全局种子。自建 RNG 或其它框架需由模型显式使用保存的种子 |
| `universe`（仅声明后） | 完整指定日来源代码/交易状态、快照批次、固定版本、17:30就绪时刻及摘要；分钟用此前已就绪交易日，不含回溯名称/当前类型/ST；来源限制见下文 |
| `data[dataset][code]` | 声明的财务数据，按报告期排序，每报告期保留当时可用的最新披露/更新值；预告按报告期与预告类型保留 |

`datasets` 支持 `universe`、`bars:d/w/m/5/15/30/60`、六类季报 `profit/operation/growth/balance/cash_flow/dupont`、`express`、`forecast`。示例清单中的 `factors/dividends` 表示引擎公司行动数据依赖，由平台记账和连续信号价格使用；不将最新前复权因子或未经时点验证的分红计划直接传给策略。`history` 的频率由清单决定；周/月和分钟策略仍须完整日线处理权益、前收盘参考与日末估值。

历史池声明、完整性、报告来源引用、七频率真实验收及回溯成员限制见[模型历史证券池输入](historical-universe-input.md)。来源实际在新代码启用前已回溯返回它，成员/状态不能单独证明当时可交易或没有前视修订。目标权重仍限固定候选 `codes`。

分钟策略的 `valuation_date` 是当前交易日，另有 `valuation_at`（已完成 bar 的完整上海时刻）及 `bar_present[code]`（该代码本周期有真实 bar）。账户按该 bar 收盘估值；财务仍只能读取公告日之后的交易日数据，不使用当日尚未披露的报告。全日停牌没有分钟 bar 时不补零行情，历史窗口停留在最后真实 bar；其它证券的市场时钟继续，停牌证券按开市已知参考价估值。

分钟数据在提交时须已到来源盘后 20:00 就绪时刻；回测内部才按历史 bar 结束时刻模拟信号。常规时段为 09:30–11:30、13:00–15:00，分钟时间字段按 bar 结束时刻解析；下一 bar 开盘执行，午休与隔夜顺延。连续 bar 的结束和下一开盘时刻相同，属于零时延近似，价格取下一根的原始开盘，成交量限制取前一根已结束 bar，不能据此声称真实盘中可成交。

输入必须满足完整时段边界、日线开收盘和成交量核对。来源分钟极值若位于日线范围内却没有达到日线极值，保留并逐项披露差异；越出日线范围、开收盘矛盾或数量缺口则停止。不用日线极值补写分钟，不支持真实触价/止损成交验证。详细事实与限制见[分钟时钟说明](research/minute-clock.md)。

日线在 17:30、周线在该周周六 17:30、月线在次月 1 日 17:30 就绪。依照 [BaoStock 主页排程](https://www.baostock.com/mainContent?file=home.md) 保守延迟，即使原始接口提前返回也不提前给策略。提交清单保存 `as_of`，回测结束日与提交时刻共同限制可见数据。周末/假日信号在下一可用交易日开盘执行；月线若在交易日 17:30 就绪，要等下一交易日，不能使用当日开盘成交。报告导出包含 `signal_events`，列明信号时刻、周期末日、估值日期。

周/月预热必须来自官方周期序列并与完整日线核对，不静默合成缺失的官方 bar。OHLC 容差 0.00001 元、成交量完全相等，成交额容差 1 元；这是平台核对政策，非来源精度承诺。真实样本存在几角的成交额差异，保留来源原值，差异写入 `period_validation` 并显示警告。超出容差停止报告。预热不产生交易；开始日至首次周期就绪间保持现金，开始日若恰为就绪日期则可产生信号。

财务公告只有日期，统一在日期之后首个交易日可用；快报取公告日期和更新日期的较晚值。报告期不代替公告日期。数据版本固定，但来源可能是当前修订的回溯值，因此不能声称恢复了首次发布原版。依据：[盈利能力](https://www.baostock.com/mainContent?file=seasonProfit.md)、[快报](https://www.baostock.com/mainContent?file=seasonExpress.md)、[预告](https://www.baostock.com/mainContent?file=seasonForecast.md)。

声明财务数据的运行在回调之前保存来源原值副本；`financial_reports` 列明报告期、公告/更新日期、保守可用规则和规范化内容摘要，`signal_events.financial_refs` 引用当次传入回调的全部报告。它不是 Python 字段读取跟踪。示例及摘要算法见[财务策略说明](financial-strategy.md)。

如模型声明财务数据，当时没有可用记录则失败。可进一步声明 `"required_fields": {"profit": ["roeAvg", "epsTTM"]}`；窗口内任一相应报告缺少这些字段则失败，空字符串、`--` 和 null 不置零。只需最新财报的模型可自行选择返回数组最后一项，但此版本的必要字段策略统一检查返回的报告历史。

行业、指数成分和无发布日期的货币供应量尚未通过历史可用时点验证，只供浏览；不可直接声明为策略必要数据。

宏观五类当前均不能声明为模型必要数据：存贷款 `pubDate` 在核对样例中对应生效日，准备金公告/生效状态及完整政策历史尚未证明，货币供应量无可靠公开日期且存在回溯口径修订。当前浏览与原值导出保留，资料页提供全量数值覆盖；不能按最后一行无限前向填充为现行政策。依据见[宏观历史可用研究](research/macro-availability.md)和[使用说明](macro-data.md)。

## 可重复运行与限制

每次提交固定模型摘要、应用包、全部已安装依赖版本、Python 版本、数据版本、提交时刻、参数和交易假设。停用策略不删除旧报告引用。历史重算使用原归档；环境版本不符时明确失败。

安装清单必须显式声明与频率一致的 `bars:频率`，省略 `datasets`、空数组或仅声明财务/公司行动/历史池均拒绝。Python 字节码缓存（`.pyc`、`__pycache__`）不作为模型源版本，安装复制与摘要计算一致忽略缓存；复制完成后再次校验摘要，源/副本不一致时不登记。含根目录编译缓存的真实包安装、61日执行、停用后完整重算及旧归档摘要核对见 [缓存包验收](verification-bytecode-package-installation.json)。

当前执行范围为 2023 年起沪深主板、科创板及创业板现金账户，支持日/周/月信号的下一日开盘成交，以及 5/15/30/60 分钟信号的下一 bar 开盘近似。已核验的 510050/510300 ETF 日线及四种分钟范围、费用、报价和来源见 [ETF 使用说明](etf-backtest.md)；两板范围与成熟样例见 [两板说明](growth-board-backtest.md)，真实跨分红分钟及其它 ETF 类别继续核验。连续价格用于信号，成交使用原始价并单独处理现金股利/送股；遇到未核验的零碎股结算停止报告。

差异化现金分红区分实际每股股利与摊薄除息金额。目前补入贵州茅台 2025-06-26，以及玲珑轮胎 2024-06-14 年度/季度同日合并的已核验公告，条款与来源固定在 `company_action_references`，实际使用时报告显示说明；未知特殊行动继续停止。核验见[差异化分红](research/differential-dividend.md)与[同日合并分红](research/joint-dividend.md)。这不改变用户固定分红税率的简化政策。

送转除权日，跨日待执行目标按已知原始开盘价格及含权益开盘净资产重算数量，避免清仓后遗留新股份；调整只在送转发生且信号来自之前日期时执行，不引入每日再平衡。买入百股取整，卖出包含全部零股余额；上市日未到的股份不能卖，部分成交剩余到期不追单。重算依据保存在订单，数量为零时撤单。规则及真实日/分钟样例见[送转股说明](research/bonus-shares.md)。

新版运行清单记录回测进程树 2 GiB 内存预算与一小时限时。工作进程每秒采样实际 RSS，记录观测峰值；超限终止任务并保留失败原因。该轮询不能保证瞬时分配绝不超过预算，也不是系统级安全沙箱。旧任务的峰值 0 表示未采样。模型应缩小股票池与预热窗口以满足预算。
