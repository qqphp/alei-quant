# 来源字段、中文名称与单位

数据中心“入库数据浏览”保留接口字段和值，可展开“字段说明与来源”，查看中文名称、单位或编码含义、该接口官方文档。当前字典包含 143 个字段，覆盖全部 26 个 SDK 数据方法实际发布过的字段；这不表示源字段或历史数据没有缺失。

- 已明确的金额、股本、周转天数及价格单位显示在名称旁；原始数值不换算。年货币量文档明确为亿元，月货币量文档没有明确单位，不借用年度单位。
- 财务接口的百分比描述与实际小数返回可能不同。例如盈利能力的 `roeAvg=0.061950` 保留为比例原值，不直接显示为 `0.061950%`，也不自动乘 100。其它未明确字段保持原值并提示文档未注明单位。
- 证券代码、文本、日期和状态码分别说明格式与含义。当前上市状态不用于历史成员过滤，名称不是历史更名序列，ETF/指数的 `isST` 不解释为股票风险警示。
- 空值显示为“—”，CSV 保留源空值；数值零保留为零。税后股利可能是多个金额或文字，不把它强制变成单一数值。正式 ETF 公告使用每份权益说明，不套股票每股说明。

19 份本轮官网正文与摘要保存在 [来源清单](research/field-docs/sources.json)，通过官网实际使用的 POST 入口读取；此前股票 K 线正文亦已保存。交易日历与指定日证券池同属官方 `StockBasicInfoAPI.md`，已修正目录原先的泛用 API 介绍链接。

真实四类资料 484 行的固定版本 HTTP/完整 CSV 与 PostgreSQL 原值核对见 [字段验收证据](verification-data-fields.json)，实际页面见 [财务字段说明](screenshots/data-field-glossary.png)与[宏观未知单位](screenshots/macro-raw-unit-glossary.png)。源缺少的单位、发布日期和首次发布原版不能由标签补造。
