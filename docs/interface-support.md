# 官方接口支持矩阵

数据中心为全部 26 个现行方法分别列出采集证据、来源覆盖、历史读取方式、支持范围、源不支持和待验证项目。目录中的方法链接指向对应官方说明。

## 三种证据分别理解

1. **采集证据**：有已发布非空批次为“采集已有非空发布”；只有成功空返回为“仅有成功空返回”；没有发布为“待采集验证”。批次数和累计接收行包含重复接收，不能作唯一证券或行情数量。
2. **来源覆盖**：统计已发布源修订行数与末期，多方法共用数据集。`bars` 展示七种原始频率；独立官方复权参考不计入原始行情。当前显示“部分覆盖”或“待验证”，不凭一个成功样本宣称全部资产/区间完整。具体区间仍用证券池、行情与每次运行的完整性检查。
3. **历史用途**：按数据族和已验证资产/日期窗口限定；源没有的字段和仍缺验证的语义分别说明。首次发布原版未证明时，不能把回溯值或抓取时间当作历史已知值。

目录一次读取固定已发布水位、方法批次及数据集统计；只读事务内一致，后台继续采集不会把同一响应的计数拼成多个版本。

## 用途边界

| 数据族 | 当前用途与限制 |
|---|---|
| 三个行情方法 | 原始行情、策略窗口、撮合与基准；日/周/月及四种分钟频率。指数只作基准。资产规则、足够预热、区间行情与权益继续逐运行校验；非日线估值与指数分钟属源不支持 |
| 证券档案 | 当前档案、类型、上市/退市、上市日期；当前状态和分类不作为历史生效版本 |
| 历史证券池 | 指定日完整成员与源交易状态；910 个已声明交易日快照已核对。名称为回溯值，分类使用固定版本档案；全部成员行情尚需回填核验 |
| 交易日历 | 就绪时间、周期、权益、区间完整检查；必要日期缺失拒绝 |
| 行业与三个指数成分 | 浏览、导出与当前参考筛选；缺少历史生效版本，不作为已支持的历史策略声明 |
| 两个因子与分红方法 | 引擎处理及来源核对，不直接传入策略；空返回不证明无公司行动，特殊权益和零碎结算未核验时拒绝 |
| 八个财务方法 | 声明后按公告时钟与固定版本读取；快报取公告/更新较晚日期，来源覆盖不足拒绝；不保证首次发布原版 |
| 五个宏观方法 | 全量浏览/导出和字段覆盖说明；利率/准备金日期、陈旧覆盖与货币历史修订不满足可靠历史输入，当前拒绝宏观模型声明 |

每方法清单及真实统计核对见 [verification-interface-support.json](verification-interface-support.json)。26 方法全部方法批次和数据集统计与独立原始 SQL 相等；空返回/未采集状态只在内存验收。零 SDK 与主库写入。浏览器实见 26 行、展开用途及来源边界，控制台 error/warn 为空；[截图](screenshots/interface-support.png)。
