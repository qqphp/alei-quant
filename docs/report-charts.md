# 报告回撤曲线与 K 线买卖点

## 回撤曲线

在完成报告的“报告曲线”选择日末净值、日末回撤；分钟报告另外提供分钟收盘净值与分钟收盘回撤。回撤为 `当前净值 / 截至当前的最高净值 - 1`，初始资金归一值 1 纳入峰值，首日亏损不能被隐藏为零。图上的负值代表距此前峰值的下降，报告最大回撤以正数展示。

分钟报告的最大回撤按分钟收盘采样，日末最大回撤另存 `daily_max_drawdown`；Sharpe、年化收益等仍按日末采样。切换曲线不改变报告、撮合、费用或账本，也不把 OHLC 内路径当成实际净值变化。

## 查看买卖点

1. 打开完成报告，选择“交易图证券”，点击“在行情页查看买卖点”。
2. 行情页 K 线按该报告的数据版本、实际回测区间和证券读取；顶部最新报价与固定历史 K 线分别注明。成交点用红色“买”和绿色“卖”标示，只包含已模拟成交的记录，不把失败订单画成成交。
3. 提示显示原始成交时刻、价格与数量。切换日线复权时仅使用该根 K 线的展示比例换算图上坐标，成交原价不改写；因子覆盖与归一限制仍按[复权说明](adjustment-data.md)显示。
4. 周/月策略以日线定位真实执行日；分钟策略按实际分钟频率定位开盘所在 K 线，来源 K 线以结束时间命名，因此不能直接把成交开盘时刻当作来源 bar 的结束时刻。午休/隔夜按该成交日的实际 slot 定位。
5. 同一证券刷新仍保持固定版本。更换证券、切换周期或点击“返回最新行情”退出买卖点视图。返回最新后沿用当前采集区间，报告本身不改动。

图表仍有明确的行情数量上限及截断提示；无法在所取窗口中定位的成交另列计数，不伪造坐标。未完成或失败报告没有此入口。此图展示回测的成交近似，不声称是真实交易所成交。

## 实际验收

16 份既有真实报告覆盖股票、财务、ETF、两板四频率分钟和周/月策略；37 组原始/前复权/后复权视图的固定版本 HTTP 行情与源价格/展示比例相符。前端实际函数核对全部成交坐标、原始价格/数量和日末/分钟回撤：共 340 个视图成交点、12767 个日末回撤点及 488 个分钟回撤点；视图包含同一成交的不同复权展示，不把这些计数当作独立交易数。

四种分钟频率的开市、午后开市及缺失时刻边界仅在内存构造；缺失成交不生成点。首日亏损使用初始资金峰值，空序列保留为空。对应代码 `frontend/src/report-charts.ts`，证据 `verification-report-charts.json`；验收没有构造值写入主库。

浏览器实见兔宝宝 18566 版本两个买卖点，筛选刷新后仍固定版本；返回最新入口清除该视图。特锐德 13245 版本分钟成交图和分钟回撤均可读取，控制台 error/warn 为空。截图 `screenshots/trade-markers-daily.png`、`drawdown-report.png`、`minute-drawdown-report.png`。TypeScript 和生产构建通过，主脚本约 767.73 kB，仍有大包提示。
